# Architecture

vantage wraps tmux. tmux stays the multiplexer and the source of truth for live
state. vantage adds saved workspaces, an SSH-aware picker, and (planned) a
sidebar TUI.

## Decisions

| Topic            | Decision                                                                                                                                                                                                                                                                                                                                                                            | Why                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Relation to tmux | A wrapper TUI: sidebar on the left, embedded tmux on the right                                                                                                                                                                                                                                                                                                                      | One always-visible sidebar, while keeping tmux's panes, keys, and persistence                                                |
| Rendering        | Embedded terminal emulator: attach a real tmux client in a PTY and draw it                                                                                                                                                                                                                                                                                                          | tmux draws panes and borders. Much less work than control mode (`-CC`), which can be adopted later                           |
| Stack            | Go: Bubble Tea, `charmbracelet/x/vt`, `creack/pty`                                                                                                                                                                                                                                                                                                                                  | One static binary. A spike confirmed truecolor, wide characters, splits, and vim                                             |
| Workspace model  | TOML definition is the source of truth. `capture` writes it from a live session                                                                                                                                                                                                                                                                                                     | Hand-editable and dotfile-friendly, with a shortcut for the common case                                                      |
| Storage          | One TOML per workspace                                                                                                                                                                                                                                                                                                                                                              | Easy diffs and sharing. See `workspace-format.md`                                                                            |
| SSH hosts        | Read `~/.ssh/config` with `kevinburke/ssh_config`. Panes run `ssh <alias>`                                                                                                                                                                                                                                                                                                          | No duplicated host list. Read-only first                                                                                     |
| Keys             | The tmux prefix (`C-a`) and all other keys pass straight to tmux. The TUI intercepts only focus keys: edge-aware `M-h` and `M-s` toggle                                                                                                                                                                                                                                             | No new prefix to learn. `M-s` guarantees an escape from panes that swallow keys                                              |
| tmux server      | Default server, with a configurable socket. Tests always use an isolated socket                                                                                                                                                                                                                                                                                                     | Existing sessions show up and can be captured. Isolation for development                                                     |
| SSH split        | `prefix S` / `V` open a `display-popup` picker (local or ssh host). `s` / `v` stay local                                                                                                                                                                                                                                                                                            | Works inside and outside the TUI                                                                                             |
| Capture          | cwd and ssh detection. Other commands are saved as `cmd` with `autorun = false`                                                                                                                                                                                                                                                                                                     | Nothing runs by surprise                                                                                                     |
| Switching        | One embedded client, `tmux switch-client`                                                                                                                                                                                                                                                                                                                                           | Simplest. tmux owns all state                                                                                                |
| Sidebar          | Tree: sessions with their windows (current one marked `*`), live dot, pane counts. `space` folds. The cursor is tracked by name                                                                                                                                                                                                                                                     | Replaces the inner tmux status bar, which is cropped from the embedded view                                                  |
| Status bar       | Cropped from the embedded view, not turned off. The embedded screen is made taller by the bar's lines                                                                                                                                                                                                                                                                               | `set status off` would also change the user's other tmux clients                                                             |
| Workspace keys   | `n` starts a session in `$HOME` and saves it. `R` renames the live session and the file. `d` deletes the file and kills the session, after `y`                                                                                                                                                                                                                                      | A workspace is the TOML. Delete asks `y/n` because it ends running work. Rename edits the file in place, so comments survive |
| SSH edit         | Writes `~/.ssh/config` directly, no diff. Atomic write, backup, re-parse before the rename, touch only the edited `Host` block                                                                                                                                                                                                                                                      | The user chose direct writes. A corrupted config is the risk, so the write is guarded in code                                |
| SSH hosts view   | `H` swaps the sidebar to hosts. `a` adds, `e` edits hostname, user, port, jump in a pop-up form (Tab moves, Enter saves, Esc cancels). `d` removes the block after `y`, keeping comments. It first warns about saved workspaces that use the alias and about live panes running `ssh <alias>`, and closes those panes. Saved workspace files are left alone The alias never changes | The alias is the identity workspaces point at. Other options (keys, forwards) stay hand-edited                               |
| SSH write guards | Follows a symlinked config. Keeps `config.vantage.bak`. Refuses CRLF, unparsable files, shared `Host a b` lines, changes that alter other hosts                                                                                                                                                                                                                                     | New `Host` blocks go before the first wildcard or `Match` section, because ssh keeps the first value it finds                |

## Notes on the TUI

Covered by tests: session and window tree, `switch-client`, `select-window`,
restore of saved workspaces from the sidebar, `M-s` toggle, edge-aware `M-h`,
key and paste passthrough, resize, mouse (sidebar click and wheel; clicks,
drags and wheel over tmux are forwarded when tmux `mouse on`), detach and
reattach, status bar cropping (bottom and top, any line count).

Known limits:

- The cursor in the embedded view is a reversed cell, because Bubble Tea
  cannot place a real cursor.
- Panes are shown as a count per window, not as tree rows.
- The status bar change is noticed on the 2 s refresh, so toggling it in tmux
  shows a short flicker of the wrong height.

## Safety

Anything that can kill or rewrite the user's real tmux or ssh state is guarded
in code, not only by convention. See `AGENTS.md`.

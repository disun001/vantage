# Architecture

vantage wraps tmux. tmux stays the multiplexer and the source of truth for live
state. vantage adds saved workspaces, an SSH-aware picker, and (planned) a
sidebar TUI.

A corrupted config is the risk, so the write is guarded in code                                |
| SSH hosts view   | `H` swaps the sidebar to hosts. `Enter` focuses the live pane running `ssh <alias>` (a pop-up lists them when there are several, `1`-`9` picks), else opens ssh in a new window of the embedded client's session. `x` lists the live panes running `ssh <alias>` and closes them all after `y`. `v` / `s` split the embedded client's active pane (side by side / stacked, via `pick.Split`) and run ssh to the selected host in the new pane. `a` adds, `e` edits alias, host, user, port, jump in a pop-up form (Tab moves, Enter saves, Esc cancels). `d` opens a confirm pop-up (`y` deletes, any other key cancels) and removes the block, keeping comments. The pop-up warns about saved workspaces that use the alias and about live panes running `ssh <alias>`, and closes those panes. It also removes the alias's panes from the saved workspace files, in place so comments survive (an emptied window goes, a window that loses panes loses its `layout` line, a workspace that would end up with no windows is left alone). Each rewritten file keeps `name.toml.vantage.bak` A new alias renames the `Host` line and repoints the `ProxyJump` hops of other blocks (user and port stay; a `Host *` default counts). It is refused when the new alias exists or a jump through the old one sits where it cannot be rewritten, such as an `Include`d file. The saved workspaces' `ssh` values follow (same guards and `.vantage.bak` as the strip). Open `ssh old` panes keep running, so each gets a tmux pane option `@vantage_renamed` = `old>new`; Enter, `x` and the delete warning find them under the new alias while their process still runs ssh to `old` | The alias is the identity workspaces point at. Other options (keys, forwards) stay hand-edited                               |
| SSH write guards | Follows a symlinked config. Keeps `config.vantage.bak`. Refuses CRLF, unparsable files, shared `Host a b` lines, changes that alter other hosts                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | New `Host` blocks go before the first wildcard or `Match` section, because ssh keeps the first value it finds                |
| Chat (planned) | `vantage chat` runs in a tmux pane and drives a long-lived `claude -p` stream-json child. Read-only (`plan` mode). Core in `internal/chat`. See `chat.md` | tmux already outlives the TUI, so no daemon. Reuses the Claude subscription login |
| Database (planned) | SQLite (`modernc.org/sqlite`) at `$XDG_STATE_HOME/vantage/vantage.db`, goose migrations, sqlc queries. Workspaces stay TOML. See `storage.md` | Chat history is queryable state for the sidebar and later hooks. Not config |

## Notes on the TUI

Covered by tests: session and window tree, `switch-client`, `select-window`,
restore of saved workspaces from the sidebar, `M-s` toggle, edge-aware `M-h`,
key and paste passthrough, resize, mouse (sidebar click and wheel; clicks,
drags and wheel over tmux are forwarded when tmux `mouse on`), detach and
reattach, status bar cropping (bottom and top, any line count).

Known limits:

- The cursor in the embedded view is a reversed cell, because Bubble Tea
  cannot place a real cursor.
- Panes are shown as a count per window, not as tree rows.
- The status bar change is noticed on the 2 s refresh, so toggling it in tmux
  shows a short flicker of the wrong height.

## Safety

Anything that can kill or rewrite the user's real tmux or ssh state is guarded
in code, not only by convention. See `AGENTS.md`.
